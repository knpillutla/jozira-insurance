# JOZIRA™ - Insurance Affiliate Website

A professional, static website for comparing USA visitor medical insurance plans. JOZIRA helps international travelers, parents, students, and business visitors understand and compare insurance options through trusted affiliate partnerships.

## Project Overview

**Brand Name:** JOZIRA™  
**Primary Domain:** https://jozira.com  
**Business Type:** Insurance Affiliate & Comparison Website  
**Version:** 1.0 (February 2026)

JOZIRA is built as a legally compliant, trustworthy, user-friendly insurance comparison platform focused on helping visitors find suitable medical insurance plans for their USA trips.

## Website Structure

The website consists of 6 main pages:

1. **Home (index.html)** - Landing page with value proposition and call-to-action
2. **About Us (about.html)** - Company mission, values, and affiliate disclosure
3. **USA Insurance (usa-insurance.html)** - Insurance comparison tool with form inputs
4. **Contact Us (contact.html)** - Contact form and FAQ
5. **Privacy Policy (privacy-policy.html)** - Data privacy and cookie policy
6. **Terms & Conditions (terms-conditions.html)** - Legal terms and affiliate disclosure

## How to Use

### Local Development
1. Clone or open this repository
2. Open `index.html` in a web browser
3. Navigate through all pages using the menu
4. All static files are ready to use

### Deployment
1. Upload all files to your hosting provider
2. Ensure all file paths are correct (css/style.css, js/script.js)
3. Configure your domain to point to the server
4. Test all pages and forms

### Customization

#### Colors
Edit the color scheme in `css/style.css`:
- Primary Dark Blue: `#001f3f`
- Secondary Blue: `#003d7a`
- Accent Red: `#ff6b6b`
- Accent Cyan: `#00d4ff`

#### Content
Edit text directly in the HTML pages. All page content is contained in semantic HTML elements for easy editing.

#### Forms
- Contact form in `contact.html` - Backend integration needed for email sending
- Comparison form in `usa-insurance.html` - Currently shows a success message; connect to actual insurance data
